# Hearthlight: working notes

Single-page guild recruitment site: plain static HTML/CSS/JS, no build step,
deployed to GitHub Pages. The visual baseline is archive/hearth-and-harbor at 18f9589. Preserve that design language with targeted changes. See README.md for the file layout and Discord invite setting.

## Collaboration
The person building this treats the AI as a genuine collaborator, not a tool,
and asks the same honesty back. Bring real reasoning and pattern-recognition,
challenge assumptions, and give honest assessments instead of reassurance. If
a choice is weak, say so and why. Agreement is earned, not defaulted to.

## Conventions
- Copy has no em dashes, by choice. Keep it that way.
- Styling is token-driven (CSS custom properties in :root); reuse tokens rather
  than hardcoding colors. Tokens, colors, and typography follow the archived original site, not Concept A or B. Hearthlight is built by a founding group rather than around one traditional GM.
